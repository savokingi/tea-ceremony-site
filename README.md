# Путь чайного мастера

Статический сайт чайных встреч. Концепция городского чайного клуба: крупная афишная типографика, кобальтовый и жёлтый, оригинальный графический натюрморт и прямой разговор с гостем.

## Предпросмотр

Из папки проекта запустить:

```sh
node preview.cjs
```

Открыть http://127.0.0.1:4173. Сервер доступен только на этом компьютере. Сборка и установка зависимостей не нужны; можно также открыть `index.html` напрямую.

## Изменения

- `index.html`: содержание, навигация, форматы встреч и приглашение.
- `styles.css`: оформление и адаптивная вёрстка.
- `app.js`: мобильное меню, выбор формата и гостей, сообщение для Telegram.
- `favicon.svg`: знак пиалы.
- `assets/tea-club.svg`: оригинальная векторная иллюстрация, нарисованная для сайта. Генерация растровых изображений не используется.

Форма открывает личный чат @midkam с черновиком сообщения. Отправку выполняет посетитель в Telegram. Формат ссылки соответствует [документации Telegram](https://core.telegram.org/api/links#public-username-links). Даты, стоимость и наличие мест остаются в анонсах канала — сайт не показывает выдуманную доступность.

Шрифты Roboto Condensed и Golos Text загружаются из Google Fonts; предусмотрены системные замены. Фотографии из старой версии сохранены в репозитории, но новый сайт их не использует.

Для публикации на существующем статическом хостинге используются `index.html`, `styles.css`, `app.js`, `favicon.svg` и папка `assets`. `preview.cjs` нужен только для локального просмотра.
